# Five visual fixes

Baseline `c21a5a41c672d6fa11c3dc81e89f832ee3ec2568`. Review branch `feat/five-visual-polishes`.

1. Brittle Bones uses the existing twelve painted bone fragments to cover the tread and the exposed face. The new renderer only reads `rubble`, places all fragments from stable section coordinates, and disposes visible textures when rewind restores an opening. It shares the existing linear surface and original bank endpoints. The unfilled abyss still uses the existing walls, lips, fog and backdrop. The fallback draws bones even if the painted atlas cannot load.
2. Reaper airborne timing joins launch and rise even after an early release, shares one apex with hover, and reserves landing poses for ground contact. Thirteen derived poses bridge the largest silhouette changes with solid coverage. The original drawings, 175 ms landing timer, action priority and airborne physics are preserved. Rebuild the 294 KiB WebP with `scripts/prepare-jump-inbetweens.py`. The existing renderer is the fallback if this optional atlas fails.
3. Registered load-bearing claws are projected onto the real slope using only generated sections. The Crawler uses the resulting visual rotation and support pivot during locomotion and standing hit reactions. Crawler and Ember Imp gait advances with their own world travel over 104 and 92 px respectively. Four extra solid in-betweens per species bridge the loops when the atlas is present. Imp warning, release and projectile state remain authoritative. Rebuild with `scripts/prepare-jump-inbetweens.py --enemies`.
4. A cold, throttled launch shows Home while Phaser preloads. If the menu opens before the first verified run pose arrives, its start button reads Preparing Reaper and shares the same tableau. Optional transition atlases stream after the opening controls mount. The two enemies now enter that same visible presentation as their images decode and breathe before the remaining opening art or gameplay assets settle. The Reaper cloak and three canopy regions use anchored Canvas warps derived from the existing paintings. Reduced motion renders still poses. The opening animation is suspended during gameplay and when hidden.

Run `tests/browser-five-polishes.js` for the focused Chromium regression. With `GRIM_POLISH_BASELINE_DIR` pointing to a checkout of the accepted revision, it also compares live simulation and RNG and can capture paired motion with `GRIM_POLISH_CAPTURE=1`.
