# Archived Biome Terrain Sprite Atlases

These eight generated sprite atlases are preserved for possible future projects or reuse. They were generated during Grim Run v0.11.15 terrain experiments and were removed from the production build when the game was restored to v0.11.10.

They are stored here as WebP files and are not loaded by the game on this archive branch. The artwork may be reused or adapted later at the user's direction.
