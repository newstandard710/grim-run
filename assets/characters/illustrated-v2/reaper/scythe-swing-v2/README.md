# Tip-first scythe sweep v2

This folder contains the corrected forward-sweep frame used as the second pose in the existing four-beat attack. Its curved cutting point leads to the right through the swing; the blunt spine trails behind. The Reaper retains the same registered feet position and gameplay scale. The other three attack poses and the 260 ms timing remain unchanged.

The 477 × 477 transparent runtime PNG is a reduced copy of the full-resolution source under `assets/visuals/review/reaper-scythe-swing-v2/source/`. The PNG's byte count and SHA-256 are checked in `assets/visuals/visual-system.js`, and the actual canvas pixels are checked by `tests/browser-visual-smoke.js`.
