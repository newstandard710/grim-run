# Reaper action art review

This review set contains the source drawings used for the four-frame scythe attack and the revised low slide. The attack contact sheet shows its wind-up, sweep, impact, and follow-through poses together. The slide pose keeps the hood and torso at normal gameplay scale while bending the knees and holding the scythe low behind the cloak.

The game uses compact runtime copies under `assets/characters/illustrated-v2/reaper/`. Both the original-size drawings here and the compact PNG files remain in the repository for future review and recovery.
